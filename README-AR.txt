خطوات الحصول على ملف AAB لجوجل بلاي (بدون أندرويد ستوديو)
=====================================================
1) انشر هذا المجلد كموقع (مجاني): 
   - netlify.com/drop  ← اسحب المجلد كله وبتاخد رابط https
   - أو GitHub Pages.
   تأكد إن الرابط بيفتح اللعبة، وإن privacy.html بيشتغل (رابط سياسة الخصوصية).
2) افتح pwabuilder.com وحط رابط موقعك واضغط Start.
   لازم يطلع المانيفست والـ Service Worker سليمين.
3) اختار Package for Stores ← Android ← Generate.
   - Package ID مثل: com.اسمك.kalimamarah (ما بيتغيّر بعدين)
   - اختار Signing key: New (جديد) ← بينزل معك ملف مفتاح signing.keystore + كلمة سر.
     *** احفظ المفتاح وكلمة السر بمكان آمن، لأنك بتحتاجهم لكل تحديث ***
4) نزّل الملف المضغوط، فيه ملف .aab جاهز لجوجل بلاي.
5) بـ Play Console: ارفع الـ aab، وأضف رابط سياسة الخصوصية، وعبّي Data safety (ما بنجمع بيانات)
   والتصنيف العمري، وصور من اللعبة.
6) حساب شخصي جديد: لازم Closed testing مع 12 شخص لمدة 14 يوم قبل النشر العام.
   تأكد من شروط جوجل الحالية بصفحة المساعدة الرسمية.
